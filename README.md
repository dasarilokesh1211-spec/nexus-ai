# Nexus AI — Business OS

React + Vite + TypeScript + Tailwind + React Router + Recharts.

## Run in VS Code
1. Install Node.js 18+ from https://nodejs.org
2. In VS Code: File > Open Folder > select this `nexus-ai` folder
3. Open the terminal (Ctrl + `) and run:

    npm install
    npm run dev

4. Open http://localhost:8080

Routes: / (landing), /dashboard, /hr, /crm, /support, /analytics, /reports
